# 2026 後端工程師實作題型

來源：`spec/後端作業題型2026.pdf`

## 第一部分：互動流程圖設計

### 主題

CPO ↔ EMSP ↔ SCSP ↔ User

### 背景說明

以 OCPI 2.2.1 為概念，製作一個時序圖（Sequence Diagram），說明用戶（User）透過第三方 App（SCSP）呼叫充電漫遊服務商 API（EMSP），來啟動充電營運商（CPO）充電設備的充電流程。

請以一個「從啟動充電到結束充電並收到帳單」的完整流程為例，使用 UML 或 Mermaid.js 繪製一張時序圖，並標註每個主要 API 呼叫與回應。

### 時序圖要求

可以忽略所有 token 認證流程，但需要包含以下事件：

- SCSP → EMSP：Start Session command
- EMSP → CPO：CommandForward
- CPO → EMSP：Session 更新（PENDING → ACTIVE）
- SCSP → EMSP：Stop Session command
- EMSP → CPO：CommandForward
- CPO → EMSP：Session 更新（COMPLETED）
- CPO → EMSP：回傳 CDR
- EMSP → SCSP：帳單結果通知

### 繳交要求

- 繳交 Mermaid.js 或 UML 格式。
- 圖中需標示角色、API 名稱與主要狀態轉換。

## 第二部分：RESTful API 設計與實作

### 主題

使用 Java（Spring Boot）設計一組會員註冊、登入與查詢系統 API。

### 功能需求

- 註冊以 Email 為帳號。
- 註冊後需要寄送開通 Email，開通信件是開通帳號的必要步驟。
- 登入使用帳號與密碼。
- 登入需加入 Email 兩階段認證，作為登入必要步驟。
- 製作一個 API，讓用戶可以查詢自己帳號的最後登入時間。
- 非本人用戶不可查詢他人的最後登入時間。

### Email 服務

- Email 寄送服務請使用 Mailjet API 或其他同類型服務，例如 SendGrid、Mailtrap。
- 申請帳號並使用免費額度即可。

### 系統架設

- 架設方式不限。
- 可以自行選擇使用 AWS、GCP 等免費額度。
- 不需要在意伺服器效能問題。

### 測試與交付

- 提供 Swagger 或 Postman collection 測試文件。
- 提供 GitHub 連結以供確認程式碼內容。
